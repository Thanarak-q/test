## What is different

- **Quota is shared with the web app.** API and web usage draw from one token quota; see
  [Models](/docs/models).
- **Two layers of rate limits** — requests and tokens — each with its own headers. See
  [Rate limits](/docs/rate-limits).
- **Errors** use this API's error format and codes, listed on [Errors](/docs/errors).
