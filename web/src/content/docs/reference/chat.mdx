## Errors

| Status | Code                           | When                                                     |
| ------ | ------------------------------ | -------------------------------------------------------- |
| 400    | `http_400`                     | Not HTTPS, or the request did not come through the proxy |
| 401    | `http_401`                     | The key is missing, wrong or not active                  |
| 413    | `http_413`                     | Input exceeds the per-request token cap                  |

| 429    | `rate_limit_exceeded_tokens`   | Token limit reached                                      |
