## สิ่งที่ต่างออกไป

- **โควตาใช้ร่วมกับเว็บแอป** การใช้งานทั้ง API และเว็บดึงจากโควตาโทเคนก้อนเดียวกัน
  ดู [Models](/docs/models)
- **Rate limit มี 2 ชั้น** คือคำขอและโทเคน แต่ละชั้นมี headers ของตัวเอง
  ดู [Rate limits](/docs/rate-limits)
- **Errors** ใช้รูปแบบและ code ของ API นี้ ดูรายการได้ที่ [Errors](/docs/errors)
