## ทำคีย์หาย

คีย์แสดงเพียงครั้งเดียวและกู้คืนไม่ได้ ให้สร้างคีย์ใหม่ในหน้า
[API Keys](/api-keys) อัปเดตแอปพลิเคชัน แล้วเพิกถอนคีย์เก่า

## ได้ 429 ทั้งที่เพิ่งเรียกไม่กี่ครั้ง

ดู error code ก่อน ถ้าเป็น `rate_limit_exceeded_tokens` แปลว่าคำขอขนาดใหญ่ไม่กี่ครั้ง
ใช้ข้อจำกัดด้านโทเคนจนหมด แม้จะส่งคำขอไม่มาก ให้ส่ง prompt ที่สั้นลงหรือลด
`max_tokens` แล้วรอ `Retry-After` วินาที ดู [Rate limits](/docs/rate-limits)

## มีคีย์มากขึ้นแล้วได้โควตาเพิ่มไหม

ไม่ได้ โควตาและ rate limit เป็นของบัญชี และทุกคีย์ใช้ร่วมกัน การมีคีย์ได้สูงสุด

<Value path="maxKeysPerUser" /> คีย์ มีไว้เพื่อแยกแอปพลิเคชัน
และเพิกถอนคีย์หนึ่งได้โดยไม่กระทบคีย์อื่น

## ได้ 401 ทั้งที่คีย์ถูกต้อง

การยืนยันตัวตนที่ไม่ผ่านทุกกรณีจะได้ 401 แบบเดียวกัน ให้ไล่ตรวจทีละข้อ

- คัดลอกคีย์มาครบ รวมถึง prefix <Value path="keyPrefix" code />
- Header เป็น `Authorization: Bearer <key>`
- คีย์ยังใช้งานอยู่ในหน้า [API Keys](/api-keys)
- เรียกผ่าน `https://`

## โควตาหมดเร็วกว่าที่คิด

โควตาของคุณใช้ร่วมกับเว็บแอป Mathew API และข้อความภาษาไทยใช้โทเคนต่อตัวอักษร
มากกว่าภาษาอังกฤษ หน้า [Usage](/usage) แยกการใช้งานตาม API และเว็บ
จึงดูได้ว่าโควตาหมดไปกับส่วนไหน
