## Unreleased

### เพิ่ม

- API keys: สร้าง ดูรายการ เพิกถอน และลบได้จากหน้า API Keys โดยคีย์แสดงเพียงครั้งเดียว
- หน้า Usage แสดงจำนวนคำขอและโทเคนรายวัน แยกตาม API และเว็บ และแยกตามคีย์
- Rate limit ด้านคำขอและด้านโทเคน แต่ละแบบมี response headers ของตัวเอง
- Header `X-Request-Id` ในทุก response
- เอกสารชุดนี้
- `POST /v1/chat/completions` ใช้กับ OpenAI SDK ได้ (ยังไม่รองรับ streaming)
- `Idempotency-Key` สำหรับคำขอ chat: ถ้าส่งซ้ำด้วยคีย์เดิม จะได้คำตอบเดิมโดยไม่เรียกโมเดลอีกครั้ง
- โควตาโทเคนที่ใช้ร่วมกันระหว่าง API key กับเว็บแอป Mathew AI คำขอที่เกินโควตาจะได้ `llm_quota_exceeded`
  ดูโควตาที่เหลือได้ในหน้า Usage
- รายชื่อโมเดลที่ admin เป็นผู้จัดการ พร้อมหน้า Models สำหรับเปิดหรือปิดโมเดล
- ข้อความให้ยืนยันตอนสร้างคีย์ ว่า prompt จะถูกส่งไปประมวลผลที่ผู้ให้บริการโมเดล

### เปลี่ยนแปลง

- Error response ระบุว่าชน rate limit ตัวไหน
- Error ของ chat ใช้ code ขึ้นต้นด้วย `llm_` ดูรายการได้ที่ [Errors](/docs/errors)
- คำขอจัดการคีย์มี rate limit ต่อบัญชี

### เลิกใช้

- ยังไม่มี

### ความปลอดภัย

- ปรับปรุงการตรวจสิทธิ์ความเป็นเจ้าของในการจัดการคีย์
- คำขอผ่าน HTTP ธรรมดาจะถูกปฏิเสธ พร้อมคำแนะนำให้เพิกถอนคีย์ที่ส่งมา
- Parameter ที่ไม่รองรับจะถูกปฏิเสธพร้อมระบุชื่อ แทนการเพิกเฉย
- ไม่ส่งต่อ error จากผู้ให้บริการโมเดลไปถึงผู้เรียกอีกต่อไป
