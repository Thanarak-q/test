## Prompt ของคุณไปที่ไหน

ระบบส่ง prompt และคำตอบไปที่ <Value path="providerName" /> เพื่อสร้างคำตอบ
วิธีจัดการข้อมูลของผู้ให้บริการรายนี้อธิบายไว้ที่ <Value path="providerPolicyUrl" />

เราไม่ส่งข้อมูลระบุตัวผู้ใช้ใด ๆ ไปกับคำขอ ทั้ง account id และคีย์ของคุณ

## สิ่งที่เราเก็บ

เราเก็บเฉพาะ metadata ได้แก่ คีย์ไหนส่งคำขอ ส่งเมื่อไร ใช้โมเดลไหน ใช้กี่โทเคน
และใช้เวลานานเท่าไร **เราไม่เก็บเนื้อหาของ prompt หรือคำตอบ**

| ข้อมูลที่เก็บ        | เก็บไว้                                         |
| -------------------- | ----------------------------------------------- |
| บันทึกการใช้งาน      | <Value path="retentionDays.usage" unit="วัน" /> |
| บันทึก audit ของคีย์ | <Value path="retentionDays.audit" unit="วัน" /> |

เมื่อครบกำหนดแล้ว ระบบจะลบข้อมูลเหล่านี้

## ถ้าคุณสร้างแอปให้คนอื่นใช้

ถ้าแอปพลิเคชันของคุณส่งข้อมูลที่คนอื่นป้อนมายัง API นี้ คุณมีหน้าที่แจ้งให้เขารู้ว่าข้อมูลไปที่ไหน
รวมถึงแจ้งว่าข้อมูลส่งถึง <Value path="providerName" />
